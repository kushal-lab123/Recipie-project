# 🍬 Recipe Project - Kushal da Dhaba

Welcome to the **Recipe Project**, a simple and clean static website showcasing recipes for classic Indian sweets (Mithai).

🔗 **Live Site:** [Kushal da Dhaba](https://kushal-lab123.github.io/Recipie-project/)

## 📖 About The Project

This project is a personal, front-end recipe website focused on presenting popular Indian dessert recipes in a clear, step-by-step format. The current version includes detailed recipes for three beloved sweets: **Barfi**, **Gulab Jamun**, and **Kaju Katli**.

The site is designed to be easy to follow for home cooks, with separate sections for ingredients and cooking processes.

## 🍰 Recipes Included

1.  **Barfi** - A fudge-like sweet made with milk powder, sugar, and ghee.
2.  **Gulab Jamun** - Deep-fried dumplings made from khoya and paneer, soaked in a cardamom-scented sugar syrup.
3.  **Kaju Katli** - A rich, thin, diamond-shaped fudge made from ground cashews.
